# Dynasty of Heroes — Official Website

Cinematic two-page website for the Dynasty of Heroes historical-fantasy project inspired by Myanmar's Pagan era.

## Pages
- `index.html` — Home: cinematic video hero, goals and objectives, story, comics/animation/game sections.
- `characters.html` — Character roster and clickable detail profiles.

## Start
Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Artwork and video assets
The text and interface are editable HTML/CSS/JS; artwork is kept separate in `assets/`.
The original MP4 videos supplied for this project are:
- `GoldenWarrior_FutureWind_Banner_CalmDark.mp4` → upload as `assets/warrior.mp4`
- `HeroesBeneaththeGoldenPagoda_banner_4K.mp4` → upload as `assets/companions-4k.mp4`

Add the supplied character portraits under `assets/portraits/<character-id>.webp` and website artwork under `assets/` as named in the HTML. If media is missing, text remains usable with gradients/fallbacks.

**Note:** This repository is currently **public**. Do not add unpublished story secrets or private project files.
